# 拍攝引導相機

這是一個可放在 GitHub Pages 的手機版靜態網頁，使用 HTML、CSS、JavaScript 製作，不需要 Java 或後端伺服器。

## 功能

- 可選擇辦公、土地、廠房三種拍攝主題。
- 每個主題提供 10 張拍攝任務，建議至少完成 8 張。
- 使用手機後鏡頭拍照。
- 在預覽畫面疊加構圖框線、透視線、邊界線與水平儀。
- 拍照後引導使用者用分享或下載方式儲存到手機。

## 使用方式

1. 將 `index.html`、`styles.css`、`app.js` 放到 GitHub Pages 網站根目錄。
2. 用手機開啟 GitHub Pages 的 HTTPS 網址。
3. 點選「CAM」開啟相機。
4. 依照任務提示拍攝，拍完後點「儲存到手機」。
5. 完成儲存後點「已儲存」，進入下一張。

## 注意

純網頁無法保證照片自動寫入手機相簿。此版本會優先使用手機分享介面，若瀏覽器不支援，則改用下載圖片。iPhone 使用者可能需要長按圖片並選擇儲存到照片。
